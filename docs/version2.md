## 002 · 选课结果导入与按周课表

- 新增“课表”页面，默认跟随当前学期周，可选周预览。单周、双周、起止周及指定周共同决定课程是否在本周上课。
- 非本周课程淡化；同一节有本周课程时隐藏非本周课程，包括只重叠部分节次的安排。真正同时上课的课程均保留并提示时间冲突。
- 支持通过照片选择器在本机进行 Vision 中英文识别，结合文字坐标匹配课程行；支持读取登录后的 HTTPS 网页、HTML/文本文件及粘贴内容。
- 首个适配器面向北京大学上方的完整选课结果表，解析一门课的多次上课安排，排除“未选上”等明确失败状态，选课状态不明时提示核对。考试信息不作为上课安排导入。
- 导入先进入预览，可修改课程名、教师、课程号、星期、节次、起止周、单双周与教室，删除误识别项或手动补充。默认合并，同课程号更新安排；可明确选择替换旧课表。
- 课表随本地状态保存，兼容未包含课表字段的旧记录。学期日期与提醒计划共用，修改学期会重建提醒；导入课程不会自动点选喝水课间。
- 新增学校适配协议和注册表，复用统一课程模型与显示逻辑。网页登录使用不写磁盘的 WebKit 会话，截图和页面识别不上传到留言服务器。

验证：已使用 Linux Swift 6.0.3 实际通过 28 项核心测试（18 项课程导入/显示测试及原有 10 项提醒测试），覆盖单双周显示、部分重叠、HTML/文字/坐标解析、无效时间、导入合并和旧状态兼容。Swift 文件语法检查通过。[代码提交 e504f62 的 GitHub Actions](https://github.com/QjCu/Weixin-Drinking-Notification/actions/runs/40114222228) 已通过 macOS 上的 28 项 Swift 测试、iPhone 模拟器编译及服务端检查；编译日志为 BUILD SUCCEEDED。实际 Vision OCR、学校登录网页、界面操作或真机通知尚未验收。

使用与扩展方法见 [课表导入与学校适配](course-import.md)。已有 Mac 工程需要在保留签名配置后重新运行 XcodeGen，以加入新增文件。

## 003 · 修复学校网页登录回跳与新窗口处理

- 修复原先将所有非 HTTPS 导航一律取消的问题：仅对北大选课网 `elective.pku.edu.cn` 与校内门户 `portal.pku.edu.cn` 的默认/80 端口允许旧版 HTTP 页面与认证回跳，IAAA 登录页保持 HTTPS。
- Debug/Release 的 ATS 配置加入上述两个精确域名例外，不放开其他子域名、不关闭证书校验，不修改留言 API 的 HTTPS 校验。
- 登录新窗口按 WebKit 提供的配置创建，保留与原页面的关联和同一临时会话；支持返回、关闭子窗口、网页脚本确认及输入，导入读取当前显示的页面。
- 补充空白子框架/登录窗口的导航处理，兼容 WebKit 为无参数 `window.open()` 提供的 nil/空 URL；仅在新窗口或已知弹窗初始化时将其视作空白页。导航错误仅显示协议和域名，不显示含登录票据的 URL 参数。关闭整个窗口时释放会话与未完成的网页对话框。
- 增加可独立测试的导航策略与回归用例，覆盖 HTTPS IAAA、HTTP 学校回跳、弹窗空白页、域名伪装、端口与凭据隔离。

验证：Linux Swift 6.0.3 的 36 项核心测试通过（含 8 项新增导航策略测试），Swift 语法及两份 plist 的域名例外检查通过。[最终修复代码 40b641e 的 GitHub Actions](https://github.com/QjCu/Weixin-Drinking-Notification/actions/runs/40849008391) 已通过 macOS 上的 36 项核心测试、iPhone 模拟器编译及服务端检查；新增 3 项真实 WebKit 运行测试全部通过，覆盖无参数打开空白登录窗口、opener 关联与共享临时会话、关闭回到原窗口、当前窗口读取及待处理确认框释放，日志为 BUILD SUCCEEDED / TEST SUCCEEDED。测试使用本地 HTML，没有访问用户账号或代填密码；真实学校登录链路需用户在手机上重新验证。使用方法见 [学校登录说明](course-import.md#北大登录回跳兼容003)。
