# 课表导入与学校适配

第 002 次修改新增“课表”页面。当前自动解析适配北京大学选课系统上方的完整选课结果表，需要包含课程号、课程名、教室信息和选课结果。仅截取下方课表网格可能缺少周次和选课状态，不适合作为当前导入来源。

## 导入课程

打开 App 的“课表 → 导入”，选择北京大学，再使用以下任一入口：

1. **选择课表截图**：从照片选择器选择清晰、完整的结果表截图。中文和英文文字由手机本地 Vision 识别，并按坐标归入课程行。图片不上传到留言服务器；识别准确度仍取决于图片质量和表格布局。
2. **打开学校网页并识别**：输入学校网站入口，按“前往”，自行登录并打开选课结果，再点“识别当前页面”。未写协议时默认 HTTPS；第 003 次修改兼容 `elective.pku.edu.cn`、`portal.pku.edu.cn` 的旧版 HTTP 页面和认证回跳，IAAA 账号密码页继续使用 HTTPS。登录由学校网页处理，App 不把账号密码发送给留言服务器。窗口使用不写磁盘的 WebKit 会话；再次打开可能需要重新登录。
3. **导入 HTML / 文本文件**：选择保存的结果页 HTML 或文本，支持 UTF-8 与 GB18030 等编码，文件最多 5 MB。网页文件按文字解析，不执行其中脚本。
4. **粘贴网页文字或 HTML**：展开粘贴入口，粘贴完整课程行，点“识别粘贴内容”。复制表格时尽量保留换行、制表符及选课状态。

网页入口可提取同源内嵌框架中的内容。跨源框架、学校登录限制或页面结构不兼容时，直接打开课表所在页面，或改用截图、文件和粘贴入口。截图建议保留原始清晰度，避免反复缩放；当前限制为 25 MB、4000 万像素。

### 北大登录回跳兼容（003）

从选课网或校内门户的入口开始登录，不要复制上一次登录后带临时票据的回跳地址。认证过程中如果出现新窗口，在新窗口完成登录；窗口关闭后会回到原页面。网页的确认框和输入框由用户响应；识别操作读取当前显示的窗口。关闭整个导入窗口会结束本次网页会话。Safari 与 App 内的临时网页会话不共享登录状态。

旧版入口与 HTTP 回跳有学校公开资料作为兼容依据（[北大教务部资料](https://dean.pku.edu.cn/userfiles/upload/download/202210061459418103.pdf)、[北大学生门户说明](https://www.sis.pku.edu.cn/docs/20191023101610679987.pdf)）。这些资料不代表当前所有登录链路均已真机验证。HTTP 例外仅限这两个完整域名的默认端口/80，不包括其他域名或子域名，也不改变留言 API 的 HTTPS 要求。

若仍然停留在登录页，记录界面显示的错误、网站域名和使用的入口地址；不要发送密码、登录回跳票据或完整带 token 的 URL。实际账号登录仍需在手机上验收。

## 核对并保存

识别结果先进入“导入预览”，此时现有课表尚未改变。每次重新识别都会替换当前预览。

- 点击课程核对和修改课程名、教师、课程号、星期、节次、周次、单双周及教室。每门课可以有多个上课安排。
- 左滑移除误识别课程；用“手动补充课程”补上缺失项。保存后也可以在“课表 → 管理”编辑或添加课程。
- 系统会排除“未选上”、候补、退选等明确未成功的课程，无法确认选课状态时给出提示。截图可能误读状态，仍应对照学校最终课表检查。
- 核对第一周的周一与学期周数。单双周依据学期第几周计算，第一周为单周，不使用自然周奇偶。
- 默认合并到现有课表：课程号相同则更新安排，其余课程保留；缺少课程号时按名称匹配。要用新学期课表替换全部旧课，开启“替换现有全部课程”，保存时确认替换。

第一周日期和学期周数与“提醒计划”共用。保存时若修改这些值，也会重建喝水提醒的学期范围。课程导入不会自动生成或点选喝水课间，继续在“提醒计划”选择所需提醒。

## 查看当前周

“课表”默认跟随当前学期周，也可以从周次菜单选择其他周，点“回到本周”恢复跟随。学期外会提示核对日期或手动选择周次。

课程按星期和“第几节”显示，尚未根据学校每节课的钟点时间生成时间轴。非本周课程显示为淡色；同一节只要有本周课程，就隐藏该节的非本周课程。因此，单双周交替上课的两门课在本周只显示应上的一门。若两门课确实在同一周同一节上课，两门均保留，并提示时间冲突。

学期周次、起止周、单双周和指定周共同决定课程是否生效。结束周之后不再视为本周课程。假期、调休、临时停课和选课系统未显示的变更仍需手动调整。

## 添加其他学校

`CourseModels.swift` 定义与学校无关的 `Course`、`CourseMeeting` 和 `CourseTimetable`。`CourseMeeting` 保存星期、起止节次、起止周、单双周、可选指定周及地点；展示由 `TimetableEngine` 统一处理。

为新学校实现 `CourseImportParser.swift` 中的 `SchoolCourseImportAdapter`：

```swift
protocol SchoolCourseImportAdapter {
    var id: String { get }
    var name: String { get }
    func parse(text: String) -> CourseImportResult
    func parse(html: String) -> CourseImportResult
    func parse(lines: [CourseOCRLine]) -> CourseImportResult
}
```

将适配器加入 `CourseImportParser.adapters`，学校选择器即可显示其名称。三种输入入口共享统一解析结果，界面、存储和按周显示无须复制实现。当前注册表只有北京大学，预留协议不代表已经支持其他学校。

新适配器应针对真实页面结构建立测试，至少覆盖多次上课、单双周、指定周、未成功选课、无效或截断时间及截图行列归属。没有把握的字段应给出警告并进入校正流程，不应猜测为确定数据。
