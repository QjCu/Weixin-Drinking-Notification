# Mac 与 iPhone 验收清单

下列为后续验收步骤，不代表已在本次环境通过。

## 编译与界面

- Mac 执行 `swift test`，通过 36 项核心测试（18 项课程导入/显示、10 项提醒算法、8 项网页登录导航策略）。
- XcodeGen 生成工程，模拟器和真机 Debug 编译启动。
- Release 可编译且拒绝 HTTP 服务端地址。
- 深色模式、大字体可阅读，课间表横向滑动可见周末。
- VoiceOver 可读出单双周、星期、时间和选择状态。

## 课表与通知

- 第一周设为当前周，点选本周对应的一格，首页下一次提醒正确。
- 单双周分别保留选择，复制只覆盖目标周课间，普通提醒不受影响。
- 改课间时间影响关联选择，删除课间不再安排关联通知。
- 添加未来两三分钟的普通提醒，锁屏和前台均能提示。
- 普通与课间同一时刻只收到一次提醒。
- 拒绝权限不显示安排成功；系统设置授权后，回到 App 恢复。
- 暂停今天保留明天，再次点击可恢复今天。
- 关闭全部、学期结束、删除所有规则后无残留通知。
- 队列最多 60 条，首页显示的最后日期正确；断网关闭 App 后仍能提醒。
- 验证跨年、学期第一周前、周日到周一和手机时区变化。

## 两人联调

- 两设备创建账号绑定，第三人无法绑定已配对账号。
- A 发一句，B 同步后在下次提醒显示昵称与留言。
- 连发两句，分别出现在接下来的两次提醒。
- 同步后改期或暂停，尚未到时的留言保留。
- 到时后再次打开和同步，不会重复安排同一句。
- 模拟发送超时，点击重试，服务端只有一条记录。
- 关闭服务端，App 报同步错误，本地课表仍能保存和安排。
- 重启服务端，账号与留言仍存在。
- 解绑定后服务端清空；对方同步后已下载的通知留言移除。
- 服务器 IP 改变，保留原数据库，通过“更新服务器地址”恢复连接。

## 课程导入与按周显示

- 从完整北大选课结果截图导入，对照学校最终课表核对全部课程及每次上课安排，未选上课程不进入预览。
- 登录学校网页读取结果、HTML 文件及粘贴表格分别测试；跨源框架受限时使用直接页面或截图。
- 切换第 1/2 周，非本周课程淡化，同一节交替课程仅显示当前周课程；真实冲突保留双方。
- 预览中修改、删除、补充课程，取消导入保留原课表；默认合并重复课程不增加副本，替换模式确认后移除旧课。
- 核对第一周日期，修改学期同时更新喝水提醒范围，但不改变原有课间点选。
- 从旧版状态升级，课程保存后重启，原提醒、账号和留言仍保留；验证深色模式、大字体和横向滚动。
- 北大网页导入从学校入口开始登录，HTTPS IAAA 认证后可回到选课网/门户的旧版 HTTP 页面；验证登录弹窗、确认框、返回原窗口与当前窗口识别。不要将带票据的旧回跳 URL 当作入口。
