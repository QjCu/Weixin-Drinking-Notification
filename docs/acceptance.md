# Mac 与 iPhone 验收清单

下列为后续验收步骤，不代表已在本次环境通过。

## 编译与界面

- Mac 执行 `swift test`，通过 10 项算法测试。
- XcodeGen 生成工程，模拟器和真机 Debug 编译启动。
- Release 可编译且拒绝 HTTP 服务端地址。
- 深色模式、大字体可阅读，课间表横向滑动可见周末。
- VoiceOver 可读出单双周、星期、时间和选择状态。

## 课表与通知

- 第一周设为当前周，点选本周对应的一格，首页下一次提醒正确。
- 单双周分别保留选择，复制只覆盖目标周课间，普通提醒不受影响。
- 改课间时间影响关联选择，删除课间不再安排关联通知。
- 添加未来两三分钟的普通提醒，锁屏和前台均能提示。
- 普通与课间同一时刻只收到一次提醒。
- 拒绝权限不显示安排成功；系统设置授权后，回到 App 恢复。
- 暂停今天保留明天，再次点击可恢复今天。
- 关闭全部、学期结束、删除所有规则后无残留通知。
- 队列最多 60 条，首页显示的最后日期正确；断网关闭 App 后仍能提醒。
- 验证跨年、学期第一周前、周日到周一和手机时区变化。

## 两人联调

- 两设备创建账号绑定，第三人无法绑定已配对账号。
- A 发一句，B 同步后在下次提醒显示昵称与留言。
- 连发两句，分别出现在接下来的两次提醒。
- 同步后改期或暂停，尚未到时的留言保留。
- 到时后再次打开和同步，不会重复安排同一句。
- 模拟发送超时，点击重试，服务端只有一条记录。
- 关闭服务端，App 报同步错误，本地课表仍能保存和安排。
- 重启服务端，账号与留言仍存在。
- 解绑定后服务端清空；对方同步后已下载的通知留言移除。
- 服务器 IP 改变，保留原数据库，通过“更新服务器地址”恢复连接。
